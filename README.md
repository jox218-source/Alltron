# Alltron

Alltron is a planned open-source Raspberry Pi household assistant. The public repository is at the **pre-alpha planning** stage; its current `main` branch does not contain an installable appliance.

The proposed first edition runs the touchscreen, local speech, household controls and Home Assistant on one Pi. Each owner supplies their own Home Assistant account and Codex CLI login for general questions. Personal-file search and the existing private PC gateway are outside this edition.

See the [stage list and privacy gates](docs/STAGES.md) for the development sequence and the [build and public development plan](docs/BUILD_AND_RELEASE_PLAN.md) for agent assignments and architecture decisions. Supported hardware and voice assets will be chosen from physical tests before installation instructions are published.
