# Getting help

Alltron is an early-stage project. Setup and supported hardware may change, and Raspberry Pi installation has not yet been validated on a dedicated project device.

## Before asking

1. Read the README and the relevant setup or troubleshooting documentation.
2. Search existing issues for the same error or behavior.
3. Confirm the project revision and follow the documented prerequisites.
4. Reproduce the issue with a clean configuration or fictional fixture where possible.

## Where to ask

- Use a GitHub issue for reproducible bugs or feature requests. Choose the closest template and include the requested details.
- Use GitHub Discussions if enabled for general usage questions. If Discussions are unavailable, open a clearly labeled question issue.
- Use the private process in [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Never put exploit details in a public issue.

## What to include

Share the Alltron revision, operating system and version, hardware model, exact redacted command, expected and actual behavior, and relevant log excerpt. Mark each item as tested, inferred, or unknown. For audio issues, describe the device and symptoms; do not upload household recordings unless the project explicitly provides a safe, consent-based process.

## What to remove first

Never post passwords, access tokens, Home Assistant long-lived tokens, Codex login data, browser profiles, full environment dumps, private IPs, public IPs, hostnames, entity names, addresses, household schedules, personal files, or unredacted audio. Replace values with `REDACTED`, `example.invalid`, or documentation-range IPs such as `192.0.2.10`. If you accidentally publish a secret, revoke it immediately; deleting the post does not invalidate it.

Support is community best-effort. No response time or compatibility guarantee is currently offered.
